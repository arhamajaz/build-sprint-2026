**BuildSprint 2026** is a two-day inter-college Startup Ideation & Innovation Challenge hosted by the **Department of Management Studies** & **Prabandhanam Society** at **BIT Mesra, Patna Campus**.

This repository contains the full production website codebase, featuring a modern split 2-column hero layout with high-definition background rocket animation, responsive countdown timer, official PDF download resources, interactive FAQ accordion, progress rings for evaluation criteria, and direct coordinator contact triggers.

---

## 🚀 Key Features

- **Split 2-Column Hero Layout**: Full-contrast left action column with high-resolution space rocket flying video player on the right.
- **Official Resources**: Direct PDF downloads for the *Event Brochure* and *Participant Guide*.
- **Interactive Lightbox**: Full-screen image modal preview for QR codes.
- **Dynamic Countdown Timer**: Live countdown ticking to September 5, 2026, 10:00 AM IST.
- **100% Fully Responsive Design**: Seamless fluid scaling across mobile phones (`320px`+), tablets, laptops, and 4K desktop viewports.
- **Help & Coordinator Contacts**: Quick click-to-call and direct WhatsApp triggers for event coordinators (Danish Iqbal & Hemant Raj).
- **Partners & Supporters**: Displaying host institute, organising body, Institution's Innovation Council (IIC), and student media network.

## 💻 Local Setup & Deployment

Since this project is built using native web standards (**HTML5**, **Vanilla CSS3**, **ES6 Javascript**), no build steps or node modules are required.

### Local Preview
Simply open `index.html` in any web browser or use VS Code Live Server:
```bash
# Using Live Server or npx serve
npx serve ./
```

### One-Click Deployment
This project can be deployed instantly to **Vercel**, **Netlify**, or **GitHub Pages**:
- **Vercel**: Import the GitHub repository and click **Deploy** (zero configuration required).
- **GitHub Pages**: Go to **Settings > Pages > Source > main branch / root**.
